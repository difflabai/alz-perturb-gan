One eligible candidate paired32
------------------------------
Exactly16 complete bags from frozen current cellshape@0.5:biascal:stagehalf
and16 bags of paired empirical cells, concatenated without modifying summary
arrays. Model bags replay the fresh current32 M32 TRAIN-only rounded joint
calibration via unchanged replay code, using valid M16 six-state/stagehalf
allocation. They are not claimed to be the first16 M32 reference bags.

Each paired empirical bag uses ONE TRAIN donor from the unchanged stage-blind
source-donor permutation cycle; exclude the target when it is a TRAIN donor.
Use target-owned library draws as the frozen empirical comparator does.
For each desired cell/library L, independently select TWO source cells from
that same source donor and the same depth-qualified pool: uniform over cells
whose library >=L; if none qualifies, deepest cell (stable sort) as before.
For j=1,2 let p_j=min(1,L/L_j). Independently draw gene counts
 Binomial(X_j, p_j/2), then sum the two integer vectors.
Selection and thinning occur in order j=1,2 within each bag. Use the same
pool/target library for both draws; do not select across different donors.
Source rows with positive counts are required for positive target libraries.

This preserves the original resampler's conditional expected count vector
including deepest-cell fallback, which is not upsampled. At fixed source
donor and target L, if the original single-cell mean/covariance are mu/Sigma,
the paired kernel has covariance .5*Sigma+.5*diag(mu); off-diagonal covariance
halves while count noise remains. These are count-space claims before log/
CP normalization. Nonzero rates, logvariance and PC summaries need not match
or improve. No summary-space contraction or postscore correction is allowed.
Outputs are artificial pooled cells, not native single cells or biological
patient vectors. Between-donor source identity remains whole-bag coherent.
