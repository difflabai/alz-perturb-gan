## Formulation and scientific interpretation

Current labels ask whether the candidate identity equals the perturbation that produced the query. They do not label disease reversal, biological equivalence or therapeutic benefit. Different genes that produce similar expression are still negatives. Successful ranking would support within-H1 response-based perturbation identification and prioritization of additional same-context experiments, if it clears meaningful controls. It cannot establish an Alzheimer's mechanism or efficacy. Arc identifies these data as H1 human embryonic stem-cell perturbations in its [primary dataset README](https://github.com/ArcInstitute/arc-virtual-cell-atlas/blob/main/virtual-cell-challenge/README.md).

The original identity-only representation leaves unseen identity columns untrained. Shared external features supply an explicit inductive hypothesis: outcome-free gene relationships predict similarities in this cell context. It is a hypothesis, not new information about a held-out outcome. [GEARS](https://www.nature.com/articles/s41587-023-01905-6) provides primary precedent for knowledge-based transfer to unseen perturbations, while also discussing cell/context and graph-coverage limits. This does not validate this implementation.

The inspected data have 48 batches with pooled controls, no donor fields and 142/150 identities with one guide assignment. Identity holdout does not remove batch/guide confounding. Randomly disjoint cells make oracle self-matching avoidable but do not create independent biological replicates. Target/seed bootstrap intervals here describe these queried identities and training randomness; they are not donor or clinical uncertainty. See [Zimmerman et al.](https://www.nature.com/articles/s41467-021-21038-1) for the statistical consequence of correlated cells.

The matched feature implementation retains `L_G = MSE(fake, unpaired cell) + 0.1 L_GAN`, public ParticleGAN0.8.0 recipe optimizers/penalty, and one D/G/J update per step. The generator is a residual MLP on a fixed pooled control, with no positivity constraint or network normalization. Single-cell reconstruction and latent draws are unpaired: analytically, its expected MSE includes generated variance, so mean shrinkage competes with distribution learning. A prior unchanged-checkpoint CPU probe observed weighted adversarial/reconstruction gradient norms 0.000161486/0.001658961, cosine -0.393227, and one-identity generated/real variance ratio 6.279e-7. These measurements apply to the original run1 checkpoint and small sampled probe, not run2 or the new feature arms. [Preserved probe and review](/ml2/altgan/particlegan-api-review-20261009/.review/delivery/alz-perturb-gan-review.md).

New diagnostics log weighted component gradient norms, their ratio/cosine, G relative parameter update, prior/projection gradients, critic/head saturation, detached realness weights and within-candidate generated variance at the first, last and every thousandth update. Nonfinite loss/gradients fail closed. This can diagnose the actual next trajectory without inferring stability from loss convergence or launching an LR sweep.

Numerical fixes: stable BCE on logits avoids sigmoid-clamp dead gradients; clearing/freezing D during G backward avoids irrelevant D gradients. Gradient routing remains J-only for the decision loss; G/J projections are separate. Protocol/objective changes: only inner-FIT identities train, candidate and target pools are disjoint for head supervision, RNG streams are separated, and frozen-head probes use an explicit unit generated-term weight because their critic is not refitted. These changes mean the new B0 is a matched baseline, not a reproduction of historical B0.

A proposed subsequent objective, **not implemented or tested here**, is to learn a conditional mean residual with replicate/pseudobulk reconstruction and, only if cell-distribution prediction is needed, fit a separately scored conditional residual distribution using a distributional objective. That removes per-draw reconstruction's variance penalty. Batch-matched control deltas, guide/batch grouped validation, no-change/mean-effect/same-feature ridge/deterministic-MLP baselines, and observed-only head training would each need a separate declared comparison. The raw sigmoid of this relativistic critic is not a calibrated realness probability; retaining its gate in the matched arms allows comparison, not a calibration claim.

## Exact evaluation artifacts

A hash-bound checkpoint is built directly without constructing a trainer. Every evaluation rejects optimizer calls and verifies all module parameters and buffers are unchanged. Historical checkpoints can be scored, but their inner scores are flagged ineligible for selecting new arms. A single saved candidate dictionary is reused across target splits, with fixed library order, exact target tensors, keyed negative identities and independent oracle candidate/query cell IDs.

Exactly four groups are written under each new evaluation directory: `inputs` (scored tensors, protocol and dictionary); `pairs` (full score matrices, JSONL pairs and negatives); `metrics` (per-target/macro/micro AUROC, rank metrics, balanced/full Brier, calibration bins, expression scores and observed/missing strata); `provenance` (source hashes, imports, package versions, environment allowlist, data/feature/checkpoint/invocation identities and artifact hash ledger). Raw sigmoid calibration is explicitly unproven. `.65` is only a displayed magnitude heuristic. Comparison helpers require paired protocol/seed/targets/negatives/profile mode and every predeclared seed; they report target and seed uncertainty, never a best-seed or two-of-three success rule. Candidate pairs are not treated as independent samples.
