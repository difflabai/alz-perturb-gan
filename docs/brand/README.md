# Official DiffLab assets

Logo files and design tokens are copied unmodified from https://branding.difflab.ai/ . The manifest records each original URL and SHA256. Marks keep their shipped geometry, color, and tilt. The PNG wordmarks are the brand guide’s authoritative rendering for external contexts.

Space Grotesk, Inter, and JetBrains Mono are served locally using the Google Fonts files recorded in the manifest. Their SIL Open Font Licenses are included alongside the fonts. Those font licenses and DiffLab’s brand usage terms apply independently of the repository’s MIT code license.
